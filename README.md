## Project Description
A Python-based application developed to automate the creation of customized revision schedules based on exam dates, syllabus size, and user-defined subject difficulty[cite: 4]. It features smart priority scoring, proportional time allocation, daily study hour logging, and progress reporting backed by persistent file storage (TXT/CSV) and robust exception handling[cite: 4, 5, 6, 8, 9].
